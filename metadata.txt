about=EN: Dynamic Field Calculator enables fast and simultaneous updating of multiple attributes in a selected vector layer, eliminating the need to repeatedly run the standard Field Calculator.

 The user selects a layer, chooses a set of fields for editing, and defines independent QGIS expressions for each of them within a single panel.
 The plugin also allows saving field and expression configurations, which streamlines repetitive operations in spatial data analysis and processing workflows.

 PL: Dynamiczny Kalkulator Pól umożliwia szybkie i jednoczesne aktualizowanie wielu atrybutów w wybranej warstwie wektorowej, z pominięciem konieczności wielokrotnego uruchamiania standardowego Kalkulatora pól.

 Użytkownik wskazuje warstwę, wybiera zestaw pól do edycji i w jednym panelu definiuje dla każdego z nich niezależne wyrażenia QGIS.
 Wtyczka umożliwia także zapamiętywanie konfiguracji pól i wyrażeń, co usprawnia wykonywanie powtarzalnych operacji w procesach analizy i przetwarzania danych przestrzennych.

changelog=
 [EN] Version 2.0.0
 * Support for QGIS 4.
 * The minimum QGIS version is now 3.34.
 * Filter vector layers by name without changing the selected working layer.
 * Long layer names no longer widen the panel.
 * Improved panel resizing: adjust the width of the field list and expression area.
 * A failed save preserves unrelated edits; undo affects only the latest plugin operation.
 * New icon and separate toolbar.
 * Improved handling of expressions that require all attributes.
 * Improved layer identification in saved configurations.
 * Improved handling of JSON fields in GeoPackage.
 * The panel is removed correctly when the plugin is disabled or reloaded.

 [PL] Wersja 2.0.0
 * Obsługa QGIS 4.
 * Minimalna wersja QGIS to teraz 3.34.
 * Filtrowanie warstw wektorowych po nazwie bez zmiany wybranej warstwy roboczej.
 * Poprawa wyświetlania nazw - długie nazwy warstw nie poszerzają panelu.
 * Usprawniono zmianę rozmiaru panelu - można zmieniać szerokość listy pól i obszaru wyrażeń.
 * Nieudany zapis zachowuje niezależne edycje; cofanie obejmuje tylko ostatnią operację wykonaną przez wtyczkę.
 * Nowa ikona oraz osobny pasek narzędzi.
 * Poprawa obsługi wyrażeń wymagających wszystkich atrybutów.
 * Poprawa identyfikacji warstw dla zapisanych konfiguracji.
 * Poprawa obsługi pól JSON w GeoPackage.
 * Panel jest poprawnie usuwany po wyłączeniu lub przeładowaniu wtyczki.
